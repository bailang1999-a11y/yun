# 喜易云 v1.59 更新说明

发布日期：2026-08-07

## 版本定位

`v1.59` 修复上游下单因瞬时 DNS、TCP 或连接超时导致订单未提交的问题。

## 主要更新

- 上游下单遇到连接建立失败时总共最多尝试三次。
- 支持 DNS 解析失败、连接被拒绝、无可用路由和连接超时重试。
- 读取超时、HTTP 错误和供应商业务拒绝不重试，避免重复充值。
- 查询请求保持原有重试行为，不改变现有订单查询和商品同步流程。

## 数据库升级

无数据库变更。

## 验证范围

- 连接失败后第三次成功。
- 连续连接失败仅尝试三次。
- 读取超时和 HTTP 5xx 下单仅尝试一次。
- 后端完整单元、并发和集成测试通过。
- `git diff --check` 通过。

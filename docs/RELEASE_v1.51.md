# 喜易云 v1.51 更新说明

发布日期：2026-08-02

## 版本定位

`v1.51` 修复阿奇索失败订单使用非法失败码，导致主动回调被拒绝、下游状态延迟同步的问题。

## 主要更新

- 阿奇索失败、退款、取消和关闭订单统一返回协议支持的 `failCode=9999`。
- 同步响应、订单查询和异步回调共用同一套失败状态映射。
- 回调签名基于修正后的失败码重新计算。
- 后端启动后自动恢复因 `FailCode的值非法` 失败的待重试和死亡回调任务。
- 历史任务恢复只重发状态通知，不重新创建订单、扣款或向上游采购。
- 任务恢复每个进程只执行一次，恢复失败时保留后续启动重试能力。

## 客户端说明

- Admin、H5、Web 无需修改；本次变更只涉及阿奇索对外协议和回调任务。

## 验证范围

- 后端完整回归测试 419 项通过。
- 阿奇索失败码白名单、同步失败响应、回调签名与历史任务恢复测试通过。
- 真实 MySQL 中的 `PENDING`、`DEAD` 历史任务恢复测试通过。
- 数据库结构和 Mapper SQL 检查通过。

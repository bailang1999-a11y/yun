# 喜易云 v1.50 更新说明

发布日期：2026-08-02

## 版本定位

`v1.50` 统一充值账号字段的兼容与归一化规则，修复阿奇索等平台因账号字段错位导致订单未创建的问题。

## 主要更新

- 多个充值账号字段按“任填一项”处理，不再要求全部字段同时满足格式校验。
- 兼容通用 `account` 以及旧模板提交的结构化字段。
- 相同账号重复提交时自动选择格式匹配的商品字段。
- 账号放错字段时会按商品候选字段重新分类。
- 不同有效账号同时提交时明确拒绝，避免充值到错误账号。
- 幂等重试比较归一化后的最终账号，兼容历史订单的旧字段结构。
- 阿奇索多账号商品模板统一返回一个“任填一项”的账号输入字段。
- 阿奇索失败审计增加商品编号、外部订单号和失败原因。

## 客户端说明

- Admin、H5、Web 无需修改；现有商品配置和前台表单已经按“任填一项”展示。
- 本次修复位于公共订单创建层，阿奇索及其他兼容协议共同生效。

## 验证范围

- 后端完整回归测试 417 项通过。
- 覆盖重复别名、错位字段、通用账号、账号冲突、历史幂等重试和失败审计。
- 覆盖七种对外兼容协议的直充下单回归。
- 数据库并发、库存、支付、订单补偿和回调任务集成测试通过。

# 喜易云 v1.45 更新说明

发布日期：2026-08-02

## 版本定位

`v1.45` 包含 `v1.44` 的阿奇索同步/异步协议与回调时序修复，并增加阿奇索下单 `maxAmount` 的独立持久化。

## 主要更新

- 完整保留 `v1.44` 的阿奇索同步/异步协议和回调时序行为。
- 订单表新增 `external_max_amount`，保存下游平台传入的整单最高可接受成本。
- 阿奇索直充和卡密下单均在 `maxAmount` 非空且校验通过后，于订单创建事务内保存该值。
- 超出 `DECIMAL(18,4)` 范围的 `maxAmount` 会在创建订单、扣款和请求上游前拒绝。
- 幂等重试失败时只清理尚未绑定订单的回调准备任务，不会终止原订单的状态回调。
- 同一会员、同一订单的重复请求只保留首次传入值，避免幂等重试覆盖原始下单数据。
- `external_max_amount` 不覆盖 `pay_amount`，不参与扣款、结算或退款。
- 空 `maxAmount` 保持为 `NULL`。

## 数据库升级

- 执行 `db/migrations/014_order_external_max_amount.sql` 后再启动新版 Backend。
- 迁移脚本可重复执行，不修改历史订单金额。

## 验证范围

- 阿奇索下单参数保存与空值单元测试。
- 真实 MySQL 首次写入、重复不覆盖、会员隔离和结算金额不变集成测试。
- 全新数据库与老库升级双路径结构校验。
- `v1.44` 与 `maxAmount` 合并发布树的完整后端回归测试。

# 喜易云 v1.40 更新说明

发布日期：2026-07-31

## 版本定位

`v1.40` 修复阿奇索异步订单缺少回调地址时仍被静默创建，导致平台只能轮询订单状态、成功时间显示滞后的问题。

## 主要更新

- 阿奇索直充和卡密下单统一要求提供非空 `callbackUrl`。
- 回调地址在订单创建和扣款前完成校验，缺失时返回明确参数错误。
- 有效请求先持久化回调任务，再创建订单，避免订单成功后无法主动通知。
- 下单成功统一返回处理中状态 `orderStatus=10`，订单进入终态后主动推送最终状态。
- 订单创建失败时清理已准备的回调任务，避免产生孤立任务。
- 保留商品不存在、商品类型不匹配和金额超限等既有错误优先级。

## 行为变更

- 缺失或空白 `callbackUrl` 的 `/order/createRecharge` 和 `/order/createPurchase` 请求返回业务错误 `code=500`、`message=callbackUrl is required`。
- 被拒绝的请求不会创建订单，也不会发生扣款。
- 已携带有效回调地址的阿奇索请求保持原有签名、响应和回调协议。

## 验证结果

- 阿奇索控制器与回调地址策略针对性测试通过。
- 后端完整测试套件：367 项通过，0 失败、0 错误、0 跳过。
- `git diff --check`：通过。

## 部署说明

- 本版本只需重建和切换 Backend 容器。
- Admin、H5、Web、MySQL 和 Redis 无需重启。
- 无数据库结构变更。
- 部署前保留源码、数据库、上传文件和旧 Backend 镜像，便于快速回滚。

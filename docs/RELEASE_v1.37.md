# 喜易云 v1.37 更新说明

发布日期：2026-07-30

## 版本定位

`v1.37` 完整实现 91/阿奇索标准货源商品价格订阅、取消订阅和价格变更通知协议。

## 主要更新

- 新增 `subscribePriceNotify` 商品价格订阅接口。
- 新增 `cancelSubscribePriceNotify` 取消价格订阅接口，重复取消按成功处理。
- 订阅时记录会员当前有效供货价作为基线，不发送无意义的首次通知。
- 后台定时检查会员有效价，价格变化后向 91 官方回调地址推送通知。
- 通知载荷包含 `supplierAccountGuid`、`productNo`、`productCost`、`priceVer`、`timestamp` 和签名。
- 签名复用阿奇索协议规则，使用 AppSecret 与会员接口密钥组合密钥。
- 官方价格通知域名 `cb-acpr.agiso.com` 已加入严格回调白名单。
- 失败通知按指数退避重试，数据库租约支持进程重启后的任务恢复。
- 每次任务领取使用唯一租约令牌，防止多实例重复完成任务或覆盖新租约。
- `priceVer` 单调递增，重复订阅不会降低已记录的版本。

## 数据库变更

- 新增 `agiso_price_subscriptions` 表。
- 唯一订阅键为会员、货源 GUID 和系统商品 ID。
- 持久化价格基线、价格版本、检查时间、租约、重试次数和失败原因。
- 新增迁移脚本 `010_agiso_price_subscriptions.sql`。

## 验证记录

- 后端完整测试套件：342 项通过，0 失败、0 错误、0 跳过。
- 真实 MySQL 覆盖订阅、取消、重复订阅、过期租约接管和旧租约隔离。
- 新库初始化与历史库逐版本升级最终结构一致：35 张表、605 项结构。
- 30 个 Mapper 的表名与列名均通过真实数据库结构校验。
- 后端生产包构建通过。
- `git diff --check`：通过。

## 影响范围

- 仅修改后端阿奇索协议、会员有效价读取和数据库持久化。
- Admin、H5、桌面 Web 页面代码无变更。
- 生产发布只需执行 `010` 迁移并重建 Backend。

## 部署说明

- 部署前备份数据库、上传目录、源码和旧 Backend 镜像。
- 执行数据库迁移后只重建并重启 Backend；Web、H5、Admin、MySQL 和 Redis 保持运行。
- 取消订阅会阻止排队和后续通知；已经发出的 HTTP 请求无法撤回，但旧任务不能回写或重新激活订阅。

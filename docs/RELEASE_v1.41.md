# 喜易云 v1.41 更新说明

发布日期：2026-07-31

## 版本定位

`v1.41` 按阿奇索标准货源协议区分同步与异步订单，修复同步商品被强制返回处理中、无回调地址订单无法创建，以及订单查询不能及时刷新上游状态的问题。

## 主要更新

- 阿奇索下单未携带 `callbackUrl` 时按同步商品处理，不再拒绝订单。
- 同步订单在请求内持续刷新上游终态，只返回 `orderStatus=20`（成功）或 `orderStatus=30`（失败）。
- 同步等待默认最长 25 秒、每 500 毫秒刷新一次，可通过后端配置调整。
- 同步等待超时返回官方其他错误码 `9999`，不会返回 `10` 或伪造成功状态。
- 携带 `callbackUrl` 的订单继续按异步商品处理，首次返回 `orderStatus=10`，终态通过持久化回调任务主动通知。
- 按阿奇索外部订单号查询时立即刷新上游状态，不再等待分钟级补偿任务。
- 保留订单号幂等：原订单号重试复用同一订单，不重复创建或扣款。
- 项目及后端构建版本同步更新为 `1.41`，确保运行日志与发布标签一致。

## 协议行为

- 同步商品：`callbackUrl` 缺失或空白，成功返回 `20`，失败返回 `30`。
- 异步商品：`callbackUrl` 非空，首次返回 `10`，完成后回调最终 `20/30`。
- 上游未在同步等待时限内给出终态时返回 `code=9999`，提示调用方使用原订单号查询，避免重复下单。

# 喜易云 v1.53 更新说明

发布日期：2026-08-03

## 版本定位

`v1.53` 增加后台商品分类拖拽排序，并完善排序预览与保存反馈。

## 主要更新

- 后台分类管理支持同级分类拖拽排序。
- 拖动经过目标位置时实时预览最终排列，其他分类卡片平滑让位。
- 松手后自动保存排序，成功后保持新位置并显示保存结果。
- 通过事务化批量接口一次保存完整同级顺序，避免部分请求失败留下交错排序。
- 保存失败时重新加载服务器顺序，避免页面顺序与实际数据不一致。
- 分类操作菜单提供“向前移动”和“向后移动”，键盘用户可通过 `Shift+F10` 完成排序。
- H5 与 Web 商城继续按后端分类顺序展示，自动继承新的排序结果。
- 支持系统“减少动态效果”设置。

## 验证范围

- Admin TypeScript 类型检查及生产构建通过。
- Backend 分类排序单元测试及完整测试通过。
- `git diff --check` 通过。

# 喜易云 v1.05 更新说明

发布日期：2026-07-27

## 版本定位

`v1.05` 是 H5 订单状态筛选的移动端导航精简版本，减少常驻选项并将低频状态收纳到“更多”菜单。

## 主要更新

- 订单状态筛选改为单行四项：全部订单、进行中、已完成、更多。
- 顶部筛选不再显示订单数量。
- “更多”下拉菜单提供全部订单、待付款、进行中、已完成、已退款、已取消六类筛选。
- 次级状态选中后，“更多”保持选中反馈，菜单内当前状态显示勾选标记。
- 支持点击外部、`Escape` 和 `Tab` 关闭菜单。
- 支持方向键、`Home`、`End` 浏览菜单项，并在关闭后恢复触发按钮焦点。
- 保留原有订单筛选规则、自动轮询、实时更新和手动刷新能力。

## 验证记录

- H5 `npm run build`：通过。
- Playwright 320px、390px、480px 手机视口验证：通过。
- 四个顶部筛选入口保持单行排列，触控高度不低于 44px。
- 顶部未渲染数量元素，“更多”包含完整六类状态。
- 六类状态逐一筛选通过，结果数量与订单接口数据一致。
- 菜单点击外部关闭、`Escape` 关闭、方向键导航和焦点恢复验证通过。
- 菜单打开与关闭状态均无页面或筛选模块横向溢出。

## 影响范围

- 仅修改 H5 订单页 `apps/h5/src/views/OrdersView.vue`。
- 不涉及 Web、Admin、后端接口或数据库迁移。

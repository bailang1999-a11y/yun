# 喜易云 v1.48 更新说明

发布日期：2026-08-02

## 版本定位

`v1.48` 增加企业微信内部群官方 Webhook 机器人的管理端配置界面。

## 主要更新

- 系统设置新增企业微信群机器人配置面板。
- 支持启停机器人、填写官方 Webhook 和校验地址格式。
- 支持分别选择新订单、支付成功、发货成功、发货失败、退款或取消、上游异常通知。
- 增加测试发送入口及最近五条发送记录展示区域。
- 明确卡密正文不进入群通知。

## 当前范围

- 本版本仅完成管理端界面和前端接口契约。
- Webhook 配置持久化、真实发送、失败重试、幂等和发送记录接口尚未接入后端。
- H5 与桌面 Web 无需修改。

## 验证范围

- Admin TypeScript 类型检查与生产构建通过。
- 本版本不修改后端服务和数据库结构。

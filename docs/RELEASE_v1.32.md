# 喜易云 v1.32 更新说明

发布日期：2026-07-30

## 版本定位

`v1.32` 修复 91 卡券撤单入口不兼容和定时任务互相阻塞导致阿奇索终态回调不发送的问题。

## 主要更新

- 阿奇索撤单接口新增 `POST /agisoAcprSupplierApi/order/cancelOrder` 兼容路径，并保留原有 `/order/cancel`。
- 两条撤单路径复用相同签名校验、会员权限、订单归属和响应结构。
- 已提交上游或已完成的订单继续安全拒绝撤单，返回 `cancelStatus=30` 和原因，不伪造退款成功。
- Spring 定时调度池由默认单线程调整为 5 线程，隔离商品监控、订单补偿和阿奇索回调任务。
- 调度池大小支持通过 `XIYIYUN_SCHEDULING_POOL_SIZE` 覆盖，默认值为 5。

## 现场问题定位

- 91 测试器实际请求撤单路径为 `/agisoAcprSupplierApi/order/cancelOrder`；旧版本没有该映射，因此返回空报文并记录 404。
- 两笔直充测试订单进入 `DELIVERED` 后，回调任务仍停留在 `PENDING`。生产日志显示共用的 `scheduling-1` 线程停止推进，符合单线程被商品监控上游调用阻塞的现象。
- 生产商品当前全部为 `DIRECT`；名称为“卡密商品测试”的商品 `10005` 实际也为直充类型，卡密成功链路不能仅靠代码修复。

## 验证记录

- 阿奇索控制器专项测试通过，覆盖旧撤单路径与 91 兼容路径的真实 HTTP POST 和完整响应字段。
- 调度配置测试通过，确认默认线程池大小为 5。
- 后端完整测试套件：313 项通过，0 失败、0 错误、0 跳过。
- 数据库全新建库与历史库升级结果均为 34 张表、585 项结构，双向差异为 0。
- 29 个 MyBatis Mapper 的表名、列名与实际结构一致。
- `git diff --check`：通过。

## 影响范围

- 修改后端阿奇索撤单路由、Spring 调度配置和对应测试。
- 无数据库结构变更。
- Admin、H5、桌面 Web 页面代码无变更。

## 部署与联调要求

- 部署后需重启后端，使新的调度池和撤单映射生效。
- 卡密联调必须通过后台管理 API 创建或转换专用 `CARD` 测试商品，并通过卡密导入 API 写入至少一张加密测试卡；禁止直接写明文数据库。
- CARD 商品必须清空直充字段和上游直充渠道，并确认 API 平台可售、对外协议允许 `CARD`。
- 91 的“带多余参数”测试当前发送空 `productNo`；后端不会放宽商品 ID 必填约束。

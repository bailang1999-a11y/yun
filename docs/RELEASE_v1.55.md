# 喜易云 v1.55 更新说明

发布日期：2026-08-03

## 版本定位

`v1.55` 让后台订单列表和汇总统计默认聚焦当天，并确保全部筛选结果统一联动。

## 主要更新

- 订单列表与顶部汇总卡片默认展示当天数据，重置筛选后同样回到当天。
- 时间、状态、发货类型和关键词筛选统一影响列表、分页总数、汇总卡片和 Excel 导出。
- 新增后端订单汇总接口，直接在 MySQL 聚合全部匹配订单，不再只统计当前分页。
- 汇总展示订单总数、外部实付金额、缺失金额数量、处理中、已发货和异常关闭数量。
- MySQL 查询与内存降级路径保持一致的筛选和状态分组语义。
- 自动刷新、订单详情更新及手动处理后会同步刷新列表和汇总。
- 加载过程中切换筛选会排队执行最新查询，避免筛选操作被自动刷新吞掉。

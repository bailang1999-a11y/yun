# 喜易云 v1.54 更新说明

发布日期：2026-08-03

## 版本定位

`v1.54` 优化后台订单管理筛选布局，并增加按订单创建时间筛选。

## 主要更新

- 订单汇总卡片移动到查找与筛选区域上方。
- 筛选栏调整为状态、发货类型、创建时间、查询、重置和搜索框顺序。
- 创建时间支持全部时间、当天、近 24 小时、近 1 周和近 1 月。
- 当天按管理端设备本地时区的当天零点计算，其余选项按滚动时长计算。
- 列表分页、总数统计和 Excel 导出统一使用订单创建时间下限。
- MySQL 查询和内存降级路径保持相同的包含边界语义。
- 非法时间参数会明确拒绝，不会静默忽略。

## 验证范围

- Admin TypeScript 类型检查及生产构建通过。
- 订单时间筛选控制器、内存降级和真实 MySQL 分页测试通过。
- 后端完整回归测试通过。
- `git diff --check` 通过。

# 喜易云 v1.13 更新说明

发布日期：2026-07-28

## 版本定位

`v1.13` 是 H5 首页分类入口的无框化与滚动体验优化版本。

## 主要更新

- 移除单个分类入口的边框、背景和圆角卡片框。
- 保留分类模块整体容器，维持页面信息层级。
- 分类图标容器放大到 `44px`，Lucide 图标放大到 `29px`。
- 长分类名称改为两份等宽文本的无缝循环滚动。
- 使用 `translate3d` 和匀速动画，减少滚动跳帧和循环停顿。
- 悬停、聚焦和按住分类入口时暂停滚动。
- 减少动态效果模式下自动关闭滚动动画。
- 保留后台图标同步、四列排列、多级分类和重置逻辑。

## 验证记录

- H5 `npm run build`：通过。
- Playwright 登录后 320px、390px、480px 手机视口验证：通过。
- 三种宽度首行均为 4 个分类入口，页面无横向溢出。
- 分类入口和图标容器边框均已移除，图标尺寸为 44px。
- 长名称滚动轨道在时间间隔内持续变化，循环动画正常运行。
- `prefers-reduced-motion: reduce` 模式下动画自动关闭。
- 分类路径切换和全部重置验证通过。

## 影响范围

- 仅修改 H5 首页 `apps/h5/src/views/HomeView.vue`。
- 不涉及后台图标配置、分类接口或其他客户端。

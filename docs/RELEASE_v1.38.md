# 喜易云 v1.38 更新说明

发布日期：2026-07-31

## 版本定位

`v1.38` 为会员开放 API 增加可选的订单状态主动通知协议，并向接入方安全交付完整订单、充值、卡密和上游处理信息。

## 主要更新

- Admin、H5、桌面 Web 统一增加可选订单状态回调地址；留空不发送通知。
- API 来源订单进入成功、失败、取消、退款或关闭状态时创建持久化通知任务。
- 阿奇索订单已携带原生回调地址时不重复发送通用会员通知。
- 请求使用现有 App Secret 做 HMAC-SHA256 验签，无需额外密钥或通知开关。
- 公开 `data` 提供订单状态摘要，`encryptedData` 使用 AES-256-GCM 交付完整敏感信息。
- 加密内容包括买家资料、充值账号与扩展字段、支付信息、全部卡号卡密、渠道记录、上游订单号、原始响应与错误及订单时间。
- 数据库内的敏感回调快照使用服务端密钥加密，不保存充值账号、卡密或上游响应明文。
- App Secret 轮换后，待发任务自动使用新 Secret 重新加密和签名。
- 同一订单重试后再次失败会生成新的状态事件；相同事件通过稳定 `eventId` 幂等。
- 回调任务支持数据库租约、指数退避、最多 20 次重试、进程重启恢复和地址变更取消。
- 回调连接固定使用已校验 DNS 地址，阻止私网、回环、链路本地地址和 DNS 重绑定。
- 非 2xx 响应体不写入任务错误或日志，避免接收方回显敏感信息。

## 数据库变更

- `member_api_credentials` 新增可选 `callback_url`。
- 新增 `member_order_callback_tasks` 持久化回调任务表及敏感快照密文列。
- `orders` 新增 `buyer_account`，保证重启恢复后仍可生成完整订单快照。
- 新增迁移脚本 `011_member_api_callback_url.sql`、`012_member_order_callback_tasks.sql`、`013_order_buyer_account.sql`。

## 协议说明

- 回调头包含 App Key、事件 ID、时间戳、签名版本和 HMAC-SHA256 签名。
- 完整敏感信息使用 App Secret 派生 AES-256-GCM 密钥，`eventId` 作为 AAD。
- 同一事件重试时 nonce 和密文可能变化，接收方必须按 `eventId` 幂等。
- 完整字段、验签和 Python 解密示例见 `docs/member-api.md`。

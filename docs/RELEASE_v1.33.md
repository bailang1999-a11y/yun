# 喜易云 v1.33 更新说明

发布日期：2026-07-30

## 版本定位

`v1.33` 修复 91 卡券回调响应格式兼容问题，使阿奇索终态回调能够被正确确认并结束重试。

## 主要更新

- 支持 91 回调接口返回的 JSON 字符串包裹格式，例如 `"{\"code\":200,...}"`。
- 保留对标准 JSON 对象响应的兼容，不影响阿奇索官方回调地址。
- 回调被拒绝时记录对方返回的业务码和消息，便于定位重试原因。
- 空响应、标量或其他非对象 JSON 继续按无效响应处理，不会误判为成功。

## 现场问题定位

- `v1.32` 已修复调度线程阻塞，生产回调任务开始正常领取和重试。
- 91 测试接口实际返回 JSON 编码后的字符串；旧客户端只解析直接 JSON 对象，因此即使内层 `code=200` 也会被判定为失败。
- 91 曾返回内层 `code=408`、`message=时间戳过期`，证明请求已到达对方，但客户端没有正确读取内层结果。

## 验证记录

- 回调客户端专项测试通过，覆盖标准响应、91 编码成功响应、91 编码拒绝响应、空响应和非对象响应。
- 后端完整测试套件：316 项通过，0 失败、0 错误、0 跳过。
- `git diff --check`：通过。

## 影响范围

- 仅修改后端阿奇索回调响应解析和对应测试。
- 无数据库结构变更。
- Admin、H5、桌面 Web 页面代码无变更。

## 部署与联调要求

- 仅需重建并重启后端，使新响应解析逻辑生效。
- 部署后检查现有回调任务能否转为 `SENT`；若对方仍返回业务拒绝，保留完整业务码和消息继续定位。
- 不修改生产商品类型、卡密库存或供应商配置。

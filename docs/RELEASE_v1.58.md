# 喜易云 v1.58 更新说明

发布日期：2026-08-07

## 版本定位

`v1.58` 将通过阿奇索身份与签名校验、但未通过业务校验的下单请求纳入后台订单追踪。

## 主要更新

- 新增独立阿奇索拒绝订单表，不让拒绝请求进入支付、库存、采购或退款状态机。
- 拒绝记录保存外部订单号、商品编号、充值账号与字段、`maxAmount`、系统要求价格和拒绝原因。
- 同一会员与外部订单号重复请求只更新一条记录并累计尝试次数。
- 后续正式下单成功时自动解决并隐藏旧拒绝记录。
- 非法签名、过期时间戳和无效身份不会写入拒绝订单表。
- 管理后台订单列表、筛选、详情和汇总支持“拒绝充值”状态。
- 悬浮拒绝状态可查看拒绝原因、外部订单号、实际支付价格和系统要求价格。
- 拒绝订单禁用退款、重试、回调刷新及手动状态操作。

## 数据库升级

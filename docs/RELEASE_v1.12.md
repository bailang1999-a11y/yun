# 喜易云 v1.12 更新说明

发布日期：2026-07-28

## 版本定位

`v1.12` 是 H5 首页分类入口的紧凑化移动端排版版本。

## 主要更新

- 分类网格调整为每行 4 个图标入口，减少模块占用高度。
- 每个图标下方保留独立分类名称区域，默认展示约 4 个字符。
- 超长分类名称在自身区域内自动横向滚动，不影响页面和相邻分类。
- 分类入口获得焦点、按住或悬停时暂停文字滚动。
- 系统开启减少动态效果时关闭跑马灯，保留可访问的文字滚动区域。
- 保留后台图标同步、多级分类、子分类箭头、选中标记和全部重置。

## 验证记录

- H5 `npm run build`：通过。
- Playwright 登录后 320px、390px、480px 手机视口验证：通过。
- 三种宽度首行均为 4 个分类入口，页面无横向溢出。
- 超长分类名称启用独立跑马灯，不影响图标和相邻文字。
- `prefers-reduced-motion: reduce` 模式下动画自动关闭。
- 分类路径切换和全部重置验证通过。

## 影响范围

- 仅修改 H5 首页 `apps/h5/src/views/HomeView.vue`。
- 不涉及后台图标配置、分类接口或其他客户端。

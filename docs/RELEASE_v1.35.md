# 喜易云 v1.35 更新说明

发布日期：2026-07-30

## 版本定位

`v1.35` 修复 91 标准货源同步和异步卡密数据无法解密的问题。

## 主要更新

- 卡密 JSON 按 91 协议使用 `AES-256-ECB + PKCS#7` 加密，再进行 Base64 编码。
- 加密密钥使用阿奇索 AppSecret 的原始 32 个 UTF-8 字节，不使用会员密钥或组合签名密钥。
- 同步卡密下单、订单查询和异步 `CreatePurchaseCallback` 统一复用相同加密逻辑。
- AppSecret 长度不符合 32 字节时明确拒绝卡密输出，避免发送无法解密的数据。
- 数据库中的卡密继续使用原有 AES-GCM 加密存储，未降低静态数据保护强度。

## 现场问题定位

- 旧实现仅将卡密 JSON 进行 Base64 编码；91 将其作为 AES 密文解密时出现无效填充错误。
- 旧版 `v1.29` 将 Base64 封装误认为双方约定的卡密加密格式。
- 91 沙箱实测只有 `AES-256-ECB + PKCS#7 + AppSecret 原始 32 字节` 返回 `code=200`；CBC、会员密钥、组合密钥和派生密钥方案均被拒绝。

## 验证记录

- 使用独立 OpenSSL 生成已知密文，并在 Java 单元测试中验证输出完全一致。
- 异步回调测试断言加密后的 `cards` 和包含密文的最终签名。
- 91 回调沙箱对确认后的加密载荷返回 `code=200`、`message=Success`。
- 后端完整测试套件：319 项通过，0 失败、0 错误、0 跳过。
- `git diff --check`：通过。

## 影响范围

- 修改后端阿奇索卡密载荷生成、同步响应、订单查询和异步回调。
- 无数据库结构变更。
- Admin、H5、桌面 Web 页面代码无变更。

## 部署与联调要求

- 仅需重建并重启后端。
- 重新测试前需保证卡密商品存在足够的本地未售卡密。
- 已泄露到聊天或日志中的 AppSecret 与会员接口密钥应在联调完成后轮换。

# 喜易云 v1.47 更新说明

发布日期：2026-08-02

## 版本定位

`v1.47` 修复管理后台订单列表和详情无法展示下游实付金额的问题。

## 主要更新

- 订单返回模型新增 `externalMaxAmount`，对应下游平台下单时传入的 `maxAmount`。
- 订单列表、详情、按请求编号查询和补偿任务查询均读取 `external_max_amount`。
- 状态更新、支付信息更新、采购结果更新和上游订单号更新后继续保留该金额。
- 订单快照回写时不会用空值覆盖已保存的下游金额。
- 同步保留充值字段和上游订单号，避免实时订单消息复制时丢失信息。

## 数据库说明

- 本版本无新增数据库结构。
- 历史订单已保存的 `external_max_amount` 会直接展示，无需补数据。

## 验证范围

- 数据库实体与订单返回模型双向映射测试。
- 真实 MySQL 写入后通过订单查询模型回读 `externalMaxAmount`。
- 状态、支付、采购和上游单号更新后的字段保留测试。
- 后端完整回归测试共 392 项，0 失败、0 错误、0 跳过。

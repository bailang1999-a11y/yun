# 喜易云 v1.34 更新说明

发布日期：2026-07-30

## 版本定位

`v1.34` 修复 91 标准货源测试中“商品不存在”响应协议不一致的问题。

## 主要更新

- 阿奇索接口遇到不存在或当前不可售的商品时，返回 91 要求的业务码 `1100`。
- 错误消息统一为 `失败原因:商品不存在`，响应中的 `data` 精确输出为 `null`。
- 可售商品继续按正常下单流程处理，不对测试商品 ID 做硬编码或特殊放行。
- 商品类型不匹配、库存不足、金额上限等其他错误码保持原有行为。

## 现场问题定位

- 91 的“商品不存在”用例使用了生产中真实存在的商品 `10004`，因此后端正确创建订单并返回 `code=200`。
- 旧版在收到真正不存在的商品 ID 时会返回 `code=1204`、英文消息和空对象 `data={}`，与 91 预期仍不一致。
- 本版本只修复阿奇索协议层的错误转换；重新测试该异常用例时仍需填写一个确定不存在的商品 ID。

## 验证记录

- 阿奇索控制器专项测试通过，新增不存在商品的完整 JSON 响应断言。
- 后端完整测试套件：317 项通过，0 失败、0 错误、0 跳过。
- `git diff --check`：通过。

## 影响范围

- 仅修改后端阿奇索错误码映射和对应测试。
- 无数据库结构变更。
- Admin、H5、桌面 Web 页面代码无变更。

## 联调要求

- 91 的正常下单用例可以继续使用商品 `10004`。
- 91 的“商品不存在”用例必须使用一个生产库中不存在的商品 ID，例如足够大的测试值；不能继续使用 `10004`。

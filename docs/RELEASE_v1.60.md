# 喜易云 v1.60 更新说明

发布日期：2026-08-13

## 版本定位

`v1.60` 隔离订单实时推送与交易主流程，并为支付后尚未提交上游的直充订单增加安全补偿。

## 主要更新

- 每个 WebSocket 会话串行发送订单事件和心跳响应，避免并发写入异常。
- 实时推送失败仅清理故障连接，不再中断支付、采购、退款或回调流程。
- 新订单支付后写入明确的“待提交上游”恢复标记。
- 直充订单支付满 10 秒仍无上游单号、无渠道尝试时，补偿任务自动提交采购。
- 补发前通过数据库状态 CAS 抢占执行权，避免多实例重复下单。
- 已有上游单号、渠道尝试或不带新版恢复标记的历史订单不会自动补发。

## 数据库升级

无数据库变更。

## 验证范围

- WebSocket 运行时异常不会从订单保存和推送链路向外传播。
- 故障会话被移除，健康会话继续接收实时事件。
- 仅无任何上游提交证据的新版直充订单进入安全补偿。
- 原有上游查单、退款、并发和订单补偿行为保持不变。
- 后端完整单元、并发和集成测试通过。
- `git diff --check` 通过。

# 喜易云 v1.24 更新说明

发布日期：2026-07-29

## 版本定位

`v1.24` 是 H5 订单状态视觉、商品标签、复制交互和多尺寸适配版本。

## 主要更新

- 统一 16 种订单状态的中文名称、语义颜色、Lucide 图标和结果页文案。
- 成功、处理中、待支付、退款、失败、取消等状态使用独立视觉反馈和克制动效。
- 订单列表增加卡密、直充、代充类型标签。
- 支持展示商品品牌、权益类型和权益时长标签，按订单来源平台读取商品详情。
- 订单号和充值账号增加明确的一键复制按钮与复制结果提示。
- 支付结果页根据真实订单状态切换标题、说明、图标、颜色和动效。
- H5 内容画布扩展至 `768px`，补充 `100dvh`、刘海屏安全区和底部导航对齐。
- 普通手机保持单列，`560px` 以上商品和订单列表自动使用双列布局。
- 所有新增动效支持 `prefers-reduced-motion`。

## 验证记录

- H5 `npm run build`：通过。
- `git diff --check`：通过。
- 320、360、375、390、414、430、480、662px 视口：无页面横向溢出。
- 320px 视口的“更多”菜单完整展示 13 个订单筛选项，未被遮挡或裁切。
- 订单号复制、充值账号复制及成功提示：通过。
- 退款中结果页显示退款语义色、处理动效和中文文案：通过。

## 已知边界

- 历史订单关联的商品如果已经售罄、下架或删除，当前后端商品详情接口不会返回其品牌、权益和时长；前端不会用虚假标签替代。后续需要在订单数据中保存商品权益快照，才能稳定展示历史信息。

## 影响范围

- 修改 H5 首页、订单列表、支付结果页、底部导航、接口归一化和全局响应式样式。
- 不修改 Admin、桌面 Web 的订单交互。
- 不修改订单业务状态、支付流程或商品源数据。
- 工作区中既有后端测试数据和脚本改动未纳入本版本提交。

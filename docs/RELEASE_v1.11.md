# 喜易云 v1.11 更新说明

发布日期：2026-07-28

## 版本定位

`v1.11` 是 H5 首页商品分类的后台图标同步与移动端网格重构版本。

## 主要更新

- H5 分类数据接入后台的 `icon`、`iconUrl`、`customIconUrl` 字段。
- 图标显示优先级为自定义上传图、图标 URL、后台图标 key、通用回退图标。
- 分类入口改为手机端三列图标网格，图标在上、文字在下。
- 分类名称最多显示两行，避免长名称挤压图标和相邻入口。
- 有子分类显示进入箭头，当前分类显示选中标记。
- 保留多级分类路径、返回上级和全部重置行为。
- 后台新增未知图标 key 时，H5 自动使用通用图标，不影响分类入口使用。

## 验证记录

- H5 `npm run build`：通过。
- Playwright 登录后 320px、390px、480px 手机视口验证：通过。
- H5 分类数量与后台分类接口数据一致。
- 分类图标容器、文字换行和三列网格无横向溢出。
- 分类点击、路径更新、子分类展示和全部重置验证通过。

## 影响范围

- 修改 H5 分类类型、接口归一化和首页分类展示。
- 不修改后台图标配置接口、Admin 页面或 Web 客户端。
- 不使用硬编码测试分类数据作为生产回退。

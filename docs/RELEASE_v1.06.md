# 喜易云 v1.06 更新说明

发布日期：2026-07-27

## 版本定位

`v1.06` 是 H5 订单状态筛选菜单的显示层级修复版本。

## 主要更新

- 修复“更多”下拉菜单被订单加载区或订单卡片遮挡的问题。
- 提升订单状态筛选导航的堆叠层级，确保菜单完整显示并可点击。
- 保留原有单行四项布局、六类状态筛选和键盘交互。

## 验证记录

- H5 `npm run build`：通过。
- Playwright 320px、390px、480px、1806px 视口验证：通过。
- 订单加载中和加载完成后，六个菜单项均位于最上层并可点击。
- 菜单打开状态无页面横向溢出。

## 影响范围

- 仅修改 H5 订单页 `apps/h5/src/views/OrdersView.vue` 的筛选导航层级。
- 不涉及筛选逻辑、Web、Admin、后端接口或数据库迁移。

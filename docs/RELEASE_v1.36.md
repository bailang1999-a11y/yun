# 喜易云 v1.36 更新说明

发布日期：2026-07-30

## 版本定位

`v1.36` 为商品列表增加系统商品 ID 精确搜索，并统一 Admin、H5 和桌面 Web 的搜索行为。

## 主要更新

- 商品统一查询支持按完整系统商品 ID 精确匹配。
- 输入部分 ID 或不存在的 ID 不会误匹配其他商品。
- 纯数字搜索只按系统商品 ID 查询，不再匹配商品名称或描述中的数字。
- 商品名称、标题、描述和平台等原有关键词搜索保持不变。
- Admin 商品列表的本地 ID 筛选改为精确匹配。
- H5 和桌面 Web 搜索框明确提示支持系统商品 ID。
- 桌面 Web 二次过滤同步支持系统商品 ID，避免后端返回的 ID 搜索结果被前端过滤。

## 影响范围

- 修改后端商品列表统一关键词过滤逻辑。
- 修改 Admin、H5、桌面 Web 商品搜索提示和前端筛选逻辑。
- 不修改商品详情、下单、库存、价格或供应商货号逻辑。
- 无数据库结构和数据变更。

## 部署说明

- 无需执行数据库迁移。

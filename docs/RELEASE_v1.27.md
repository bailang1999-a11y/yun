# 喜易云 v1.27 更新说明

发布日期：2026-07-29

## 版本定位

`v1.27` 为喜易云对外供货协议兼容版本，向下游平台提供统一货源能力。

## 主要更新

- 新增卡速售、咔咔云、福禄新平台、蜂助手、鼎信橙券、浙江梵尘、京兆云七套兼容协议。
- 七套协议均支持余额查询、商品查询、订单创建和订单查询。
- 卡密与直充订单复用会员订单流程，并支持外部订单号幂等。
- 按会员配置 AppKey、AppSecret、IP 白名单和每日调用上限。
- 增加全局每分钟限流、协议开关、商品开放范围和交付类型配置。
- 协议设置、商品范围和调用日志接入持久化存储。
- 管理后台新增真实配置与调用日志页面，权限归入 `goods:manage` 并保持默认拒绝策略。

## 已知边界

- 本版本支持下游主动查询订单状态。
- 下游异步推送回调和持久化重试队列尚未实现；需要推送交付结果的平台应暂时使用订单查询接口轮询。

## 影响范围

- 修改管理后台对外供货协议配置页及其 API 接入。
- 新增后端七协议控制器、鉴权、限流、订单适配、配置持久化和调用日志。
- 不修改 H5 与桌面 Web。该功能面向下游 API 采购方，不改变现有商城商品展示和购买流程。
- 不包含远程推送或生产部署。

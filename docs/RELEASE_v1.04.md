# 喜易云 v1.04 更新说明

发布日期：2026-07-27

## 版本定位

`v1.04` 是 H5 订单页信息精简版本，移除无须向用户持续展示的订单同步状态提示。

## 主要更新

- 移除订单页“状态已同步”和“正在同步订单状态”提示条。
- 保留每 8 秒自动刷新订单状态。
- 保留实时订单事件订阅和自动更新。
- 保留手动刷新按钮的加载与禁用反馈。
- 保留 6 个订单状态固定三列、两行筛选布局及数量统计。

## 验证记录

- H5 `npm run build`：通过。
- Playwright 320px、390px、480px 手机视口验证：通过。
- 同步提示条在三种视口下均不存在。
- 页面和状态筛选模块均无横向溢出。
- 6 个筛选按钮逐一点击通过，数量徽标与实际订单列表条数一致。

## 影响范围

- 仅修改 H5 订单页 `apps/h5/src/views/OrdersView.vue`。
- 不涉及 Web、Admin、后端接口或数据库迁移。

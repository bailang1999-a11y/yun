# 喜易云 v1.57 更新说明

发布日期：2026-08-03

## 版本定位

`v1.57` 统一上游采购下单价格口径，隔离用户实付金额与上游采购成本。

## 主要更新

- 采购价格优先使用当前渠道的上游采购单价，缺失时回退本地商品基础售价。
- 凡尘、咔咔云、福禄、蜂助手和京兆的价格校验字段统一传采购总成本。
- 卡速售和鼎信橙券协议没有采购价格字段，保持原协议请求结构。
- 自动采购和管理员指定渠道重试使用相同价格规则。
- 供应商余额校验改用采购总成本，不再使用用户实付金额。
- 采购成本独立写入订单 `cost_amount`，后续快照不会以空值覆盖。

## 验证范围

- 渠道采购价优先、本地售价回退及多数量成本计算测试通过。
- 五家含价格字段的上游请求测试确认不再传用户实付金额。
- 真实 MySQL 成本持久化测试通过。
- 后端完整回归通过。
- `git diff --check` 通过。

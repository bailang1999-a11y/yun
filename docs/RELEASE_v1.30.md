# 喜易云 v1.30 更新说明

发布日期：2026-07-30

## 版本定位

`v1.30` 为 91卡密标准货源实测兼容修复版本，修正商品列表字段类型和时间戳过期边界。

## 主要更新

- `disableSaleChannels` 不再返回 JSON 数组；无禁售渠道时返回 `null`，有值时返回英文逗号连接的字符串，兼容 91卡密的可空字符串模型。
- 时间戳有效范围调整为严格小于 600 秒，正负方向达到 600 秒时统一返回 `408`。
- 时间戳改为上下界比较，异常大或异常小的外部时间戳稳定判定为过期。
- 新增空渠道、非空渠道、JSON `null`、599/600 秒边界和极端时间戳回归测试。

## 验证记录

- 91卡密测试工具已复现并定位商品列表字段解析和 600 秒边界问题。
- 阿奇索 Controller 专项测试：6 项通过，0 失败。
- 后端完整测试套件：302 项通过，0 失败、0 错误。
- `git diff --check`：通过。

## 已知边界

- 本版本不执行真实直充或卡密订单测试，避免产生上游采购和资金变动。
- 跨重启的持久化回调重试队列尚未实现。

## 影响范围

- 仅修改阿奇索标准货源 Controller、专项测试和版本说明。
- Admin、H5、桌面 Web 以及数据库结构均无变更。

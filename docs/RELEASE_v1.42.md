# 喜易云 v1.42 更新说明

发布日期：2026-08-01

## 版本定位

`v1.42` 修复 Web 与 H5 创建订单超时后前台误报失败、后台仍生成未支付订单，以及用户重试产生重复订单的问题。

## 主要更新

- Web 与 H5 单次购买使用稳定的 `requestId`，超时重试不再生成新的请求编号。
- 创建订单响应不确定时，前台按 `requestId` 查询后台订单；已创建的未支付订单直接进入支付页。
- Web 与 H5 接口超时统一调整为 20 秒，并区分明确业务失败与网络结果不确定。
- 新增登录态 `GET /api/h5/orders/by-request/{requestId}`，只能查询当前会员自己的订单。
- 生产订单创建路径不再持有 JVM 全局 `orderLock`，不同用户下单不再互相排队。
- 订单写入和非卡密商品库存扣减合并到同一个数据库事务，失败自动回滚。
- `(user_id, request_id)` 唯一索引承担并发幂等；同一请求只生成一笔订单、扣一次库存。
- 新订单实时广播改为事务提交后异步执行，慢 WebSocket 客户端不再阻塞下单响应。
- 超过 1 秒的订单创建请求记录慢日志，便于线上定位数据库或网络异常。

## 验证结果

- 后端完整测试套件：375 项通过，0 失败、0 错误、0 跳过。
- 同一 `requestId` 20 路并发仅生成一单并扣一次库存。
- JVM 全局订单锁被占用时，生产订单创建仍可独立完成。
- WebSocket 发送阻塞时，订单创建接口仍可及时返回。
- Web 与 H5 生产构建通过。
- `git diff --check`：通过。

## 部署说明

- 本版本需要重建并切换 Backend、Web 和 H5 容器。
- Admin、MySQL 和 Redis 无需重启。
- 无数据库结构变更。
- 部署前保留源码、数据库、上传文件和旧容器镜像，便于快速回滚到 `v1.41`。

# 喜易云 v1.10 更新说明

发布日期：2026-07-28

## 版本定位

`v1.10` 是 H5 首页商品分类的图标化展示版本，让移动端分类入口更容易识别和点击。

## 主要更新

- 分类按钮增加 Lucide 图标和分类文字组合展示。
- 影视、游戏、人工服务、话费流量、数字权益等分类按名称匹配对应图标。
- 未识别的新分类自动使用通用分类图标，不依赖固定分类数据。
- 当前分类选中态同时高亮图标和文字，子分类继续保留进入箭头。
- 分类重置按钮增加“全部”网格图标。
- 保留现有动态分类数据、多级分类跳转、返回上级和重置逻辑。

## 验证记录

- H5 `npm run build`：通过。
- Playwright 登录后 320px、390px、480px 手机视口验证：通过。
- 10 个动态分类均渲染可见图标，分类文字未被裁切。
- 分类按钮点击、分类路径更新和“全部”重置验证通过。
- 页面和分类容器均无横向溢出。

## 影响范围

- 仅修改 H5 首页 `apps/h5/src/views/HomeView.vue`。
- 不涉及商品分类接口、后端、Admin 或 Web 客户端。
- 工作区中其他既有变更未纳入本版本提交。

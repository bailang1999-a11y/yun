# 喜易云 v1.46 更新说明

发布日期：2026-08-02

## 版本定位

`v1.46` 在完整保留 `v1.45` 阿奇索回调与 `maxAmount` 原子持久化修复的基础上，重构管理后台订单运营视图并修复审计日志重启后的编号冲突。

## 主要更新

- 订单列表按可视区域动态计算每页数量，只展示完整可见的订单行。
- 创建时间、处理耗时和本地订单号前置，订单号与充值账号支持点击复制。
- 实付金额展示下游传入的 `maxAmount`，成本金额继续展示平台用户实际支付金额。
- 点击订单行可在列表内展开完整详情、交易链路、发货采购信息和尝试时间线。
- 阿奇索标准货源订单来源统一展示为“抖音API 下单”。
- 订单状态改为图标文字卡片，并与处理耗时共用蓝、绿、红语义颜色。
- 审计日志服务启动时从数据库最大编号续号，避免重启后主键冲突导致日志静默丢失。
- 保留 `v1.45` 的阿奇索异步回调时序、幂等保护和 `external_max_amount` 原子保存行为。

## 数据库升级

- 从 `v1.44` 或更早版本升级时，启动新版 Backend 前执行 `db/migrations/014_order_external_max_amount.sql`。
- 已执行该迁移的环境可以安全重复执行，脚本不会修改历史订单金额。

## 验证范围

- Admin TypeScript 检查与生产构建。
- 后端完整单元测试和 MySQL 集成测试。
- 数据库初始化与增量迁移结构一致性检查。
- 部署后检查 Backend、Admin 健康状态及订单列表接口。

## 部署说明

- 部署前备份生产数据库、环境文件和当前应用目录。
- 执行数据库迁移后重建并切换 Backend 与 Admin。
- 回滚应用时数据库新增列可以保留，不影响旧版本运行。

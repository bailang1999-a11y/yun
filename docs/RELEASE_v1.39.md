# 喜易云 v1.39 更新说明

发布日期：2026-07-31

## 版本定位

`v1.39` 修复桌面 Web 商城一次加载全部商品造成的网络等待、DOM 膨胀和主线程卡顿。

## 主要更新

- Web 商品列表改为后端分页，每次只请求并渲染 20 个商品。
- 分类筛选直接向后端传递分类 ID，继续覆盖全部子分类商品。
- 商品名称、系统商品 ID 和面值搜索改为服务端检索，并在搜索后回到第一页。
- 列表展示真实商品总数、当前显示区间和页码。
- 增加上一页、下一页图标按钮，并在加载期间锁定分类操作，避免重复请求。
- 保留窗口重新聚焦时刷新真实后台数据的行为。

## 性能验证

- 首屏商品接口请求从 19 次降为 1 次。
- 首屏商品卡片从约 1859 张降为 20 张。
- 浏览器 DOM 节点从 115834 降至 1724。
- 布局对象从 106454 降至 1565。
- 事件监听器从 2129 降至 206。
- 浏览器主线程任务耗时从约 3.10 秒降至约 0.35 秒。

## 功能验证

- Web 翻页请求正确携带 `page` 和 `pageSize`。
- 系统商品 ID `10005` 精确搜索返回唯一商品。
- 分类筛选正确携带 `categoryId`，并展示分页后的分类商品。
- Admin、H5、Web 生产构建通过；H5 与 Admin 原有分页行为不变。
- 后端完整测试套件：366 项通过，0 失败、0 错误、0 跳过。
- 新库初始化与历史库逐版本升级结构一致：36 张表、632 项结构。
- 31 个 Mapper 与真实数据库结构校验通过。
- `git diff --check`：通过。

## 部署说明

- 本版本仅需重建和切换 Web 容器。
- Backend、Admin、H5、MySQL 和 Redis 无需重启。
- 部署前保留旧源码、环境文件和 Web 镜像，便于快速回滚。

# 喜易云 v1.02 更新说明

发布日期：2026-07-27

## 版本定位

`v1.02` 是本地开发体验与测试覆盖增强版本，重点优化 H5 商品分类的手机端交互，并补充可重复加载、验证和清理的全系统测试数据。

## 主要更新

### H5 商品分类

- 移除横向滑动分类条，改为适合手机触控的两列分类网格。
- 分类名称支持完整换行，避免长名称被截断。
- 新增返回上一级、查看全部、当前分类路径、层级和数量状态。
- 子分类使用方向图标提示，当前分类提供明确选中反馈。
- 分类按钮最小高度为 52px，覆盖 320px、390px 和 480px 手机视口。
- 保留原有分类筛选、商品加载、搜索和分页行为。

### TEST-V101 测试数据

- 新增 40 个分类节点，组成 8 条完整五级分类链。
- 新增 180 个商品，`CARD`、`DIRECT`、`MANUAL` 各 60 个。
- 新增 36 个测试用户、6 个用户组和登录密码配置。
- 新增 600 张 AES-GCM 有效加密卡密，覆盖未售、锁定和已售状态。
- 新增 156 个订单，完整覆盖 13 种订单状态，每种 12 条。
- 覆盖支付、回调、退款、履约、短信、操作日志和会员 API 数据。
- 覆盖 H5、Web、PC、API、禁售、无限制、库存、金额、空值、长文本和 Unicode 边界。
- 测试供应商仅指向 `127.0.0.1:9`，禁止真实上游外呼。

# 喜易云 v1.44 更新说明

发布日期：2026-08-01

## 版本定位

`v1.44` 修正阿奇索标准货源协议的商品接口类型和异步订单状态顺序。

## 主要更新

- 卡密商品按同步接口 `apiType=1` 对外提供，直充商品按异步接口 `apiType=2` 对外提供。
- 下单模式由商品类型决定，不再根据请求是否携带 `callbackUrl` 猜测。
- 异步直充订单缺少回调地址时，在创建订单、扣款和请求上游前直接拒绝。
- 异步直充下单固定先返回 `orderStatus=10`，最终成功或失败由后台任务回调。
- 回调任务绑定后保留 2 秒响应窗口，避免最终状态回调早于下单响应。
- 卡密同步订单保持直接返回最终状态，不创建异步回调任务。

## 验证范围

- 阿奇索控制器与回调服务单元测试。
- 回调任务持久化集成测试，覆盖绑定前不可调度、绑定后按释放时间调度。
- 后端完整测试，共 `385` 项，`0` 失败、`0` 错误、`0` 跳过。
- 生产配置预检通过；部署后需执行服务健康检查。

## 部署说明

- 本版本无数据库结构迁移。
- 仅需重建 Backend；整套 Compose 可保持其他服务不变。
- 回滚点为 `v1.43`。

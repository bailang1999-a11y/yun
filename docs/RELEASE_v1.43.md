# 喜易云 v1.43 更新说明

发布日期：2026-08-01

## 版本定位

`v1.43` 增加独立 API 域名和供应商默认回调地址，并缩短缺少有效回调的直充订单状态同步时间。

## 主要更新

- 独立接口域名默认使用 `https://api.xiyi.co`，新对接不再依赖管理后台域名。
- 新增独立 API Nginx 配置，只开放会员、支付、上游回调和兼容供货协议等机器接口。
- 供应商订单通知地址按公共 API 域名和供应商 ID 自动生成并展示，仍可手动覆盖。
- 默认回调地址在下单时传给支持异步通知的蜂助手、鼎信橙券、浙江梵尘和京兆云。
- 每笔直充订单记录实际发送给上游的回调地址，避免供应商配置变更影响历史订单判断。
- 未向上游发送有效回调地址的直充订单，从支付满 10 秒起每 10 秒真实查询一次上游状态。
- 快速查单候选由 MySQL 按商品类型、订单状态、时间和回调状态筛选并限量，不再加载历史订单全表。
- 旧订单没有回调快照时自动进入快速查单，兼容升级前的进行中订单。
- 兼容京兆回调 `cards=[]` 不参与签名的规则，避免真实异步通知被误判为验签失败。
- 修正数据库结构检查器对 MySQL `JSON_TABLE` 表函数的误判。

## 验证结果

- 后端完整测试套件：382 项通过，0 失败、0 错误、0 跳过。
- 快速查单 MySQL 集成测试通过，覆盖时间阈值、回调排除、商品类型、订单状态、排序和批次上限。
- H5、Web、Admin 三端生产构建通过。
- 全新数据库与老库升级结构双向对比通过，31 个 Mapper 与实际结构一致。
- 生产配置预检、Docker Compose 渲染和 Nginx 配置语法检查通过。
- `git diff --check`：通过。

## 部署说明

- 本版本无数据库结构迁移。
- 部署时重建 Backend 与 Admin；Web、H5 可随整套 Compose 一并重建。
- `.env` 的 `API_PORT` 默认使用 `18089`，Backend 仅绑定到 `127.0.0.1`。
- 将 `deploy/nginx/api.xiyi.co.conf` 安装到宿主机 Nginx，并在容器切换后执行配置测试和 reload。
- 部署前保留源码、数据库、上传文件和旧容器镜像，回滚点为 `v1.42`。

# 喜易云 v1.03 更新说明

发布日期：2026-07-27

## 版本定位

`v1.03` 是 H5 订单页移动端操作体验优化版本，重点重构订单状态筛选模块。

## 主要更新

- 移除订单状态筛选的横向滚动。
- 6 个订单状态改为固定三列、两行的分段网格。
- 每个状态增加实时订单数量，筛选结果更容易预判。
- 选中状态增加明确的颜色、边框和数量反馈。
- 筛选按钮最小高度为 50px，适合手机触控。
- 保留原有全部、待付款、处理中、已完成、已退款、已取消筛选规则。
- 增加 `aria-pressed` 状态，改善辅助技术识别。

## 验证记录

- H5 `npm run build`：通过。
- Playwright 320px、390px、480px 手机视口验证：通过。
- 订单状态筛选固定为 3×2，无页面或模块横向溢出。
- 6 个筛选按钮逐一点击通过，数量徽标与实际订单列表条数一致。
- H5 页面返回 HTTP 200，后端健康状态为 `UP`。

## 影响范围

- 仅修改 `apps/h5/src/views/OrdersView.vue`。
- 不涉及 Web、Admin、后端接口或数据库迁移。

# 喜易云 v1.56 更新说明

发布日期：2026-08-03

## 版本定位

`v1.56` 完善后台订单列表的商品履约表现与上游采购价格展示。

## 主要更新

- 订单列表新增商品近 100 笔有效完成订单的平均充值耗时。
- 同一标签展示商品当天成功率，按上海时区的订单创建时间统计。
- 成功率仅统计已发货与失败终态，处理中、待支付等状态不进入分母。
- 悬浮标签展示“近100单平均耗时”和“今日成功率”明细。
- 金额列新增上游采购价趋势，展示最新采购价及近 10 次价格时间点。
- 新增供应商采购价历史表，商品监控更新价格时记录历史数据。

## 数据库升级

已有生产数据库需在启动新后端前执行：

```bash
db/migrations/016_supplier_price_history.sql
```

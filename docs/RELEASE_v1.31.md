# 喜易云 v1.31 更新说明

发布日期：2026-07-30

## 版本定位

`v1.31` 为阿奇索 / 91卡密异步订单回调可靠性修复版本，补齐此前缺失的跨状态、跨重启回调闭环。

## 主要更新

- 阿奇索异步订单在创建前持久化回调任务，订单创建后绑定本地订单号，避免处理中订单丢失回调地址。
- 新增带租约的回调 Worker：订单进入成功或失败终态后自动签名通知，进程重启后可继续处理未完成任务。
- 回调发送失败采用指数退避重试，最多 20 次；数据库原子领取防止请求线程与定时任务重复发送。
- 查询接口与回调共用同一套订单载荷和状态映射；`REFUNDING` 保持处理中，完成退款后才返回失败终态。
- 修复库存不足错误被商品不存在分支提前匹配、错误返回 `1204` 的问题，现在返回 `1208`。
- 直充与卡密测试回调地址继续执行域名白名单校验，不在任务表保存 AppSecret 或会员接口密钥。
- Web Nginx 新增 `/agisoAcprSupplierApi/` 后端转发，确保 `api.xiyi.co` 对外兼容接口可接收 POST 请求。

## 数据库变更

- 新增 `agiso_callback_tasks` 表，记录外部订单号、本地订单号、回调地址、任务状态、尝试次数、下次执行时间和租约。
- 新增升级脚本 `db/migrations/009_agiso_callback_tasks.sql`。
- 全新建库脚本和集成测试 SQL 副本已同步。

- 修改后端阿奇索协议、回调任务持久化、定时 Worker、数据库结构和对应测试。
- Admin、H5 前端代码无变更；桌面 Web 仅增加服务器端反向代理，不改变商城页面展示或购买流程。

## 部署要求

- 既有数据库必须先执行 `db/migrations/009_agiso_callback_tasks.sql`，再启动 `v1.31` 后端。
- 部署后使用 91卡密测试工具分别验证直充、卡密的异步回调和订单查询；交易测试应使用无真实采购风险的专用测试商品。

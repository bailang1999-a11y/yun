# 喜易云 v1.49 更新说明

发布日期：2026-08-02

## 版本定位

`v1.49` 完成企业微信内部群官方 Webhook 机器人的后端发送与可靠交付能力。

## 主要更新

- 系统设置支持保存企业微信官方机器人 Webhook 和六类独立通知开关。
- Webhook 使用现有卡密加密服务加密落库，后端重启后可恢复配置。
- 新订单、支付成功、发货成功、发货失败、退款或取消、上游异常可异步通知。
- 通知包含订单、商品、金额、用户、充值、支付、时间和错误信息，卡密正文不进入群通知。
- 新增持久化通知任务、幂等事件编号、任务租约、指数退避重试和发送记录。
- 新增测试发送和最近发送记录接口，并纳入 `settings:manage` 权限。
- H5 公共设置接口不会返回机器人 Webhook。
- 管理端与后端统一企业微信官方 Webhook 地址校验规则。

## 数据库说明

- 新增迁移 `015_wecom_robot_delivery_tasks.sql`。
- 迁移只新增 `wecom_robot_delivery_tasks` 表，不修改现有订单和配置数据。

## 验证范围

- 后端完整回归测试 411 项通过。
- 企业微信配置、消息内容、重试、幂等、事务登记和数据库结构测试通过。
- Admin TypeScript 类型检查与生产构建通过。
- 全新数据库与历史数据库迁移后的结构双向对比通过。

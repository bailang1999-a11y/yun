# 喜易云 v1.14 更新说明

发布日期：2026-07-28

## 版本定位

`v1.14` 是 H5 首页商品分类的紧凑图标导航与开发预览版本。

## 主要更新

- 分类入口保持每行 4 个，移除单个入口的边框和背景卡片。
- 图标区域调整为 `48px`，Lucide 图标调整为 `38px`。
- 移除分类入口右侧箭头，选中分类继续保留状态标记。
- 将分类层级和数量并入“商品分类”标题行，减少模块占用高度。
- 长分类名称使用 `translate3d` 无缝循环滚动。
- 新增 13 张本地开发图标预览资源，按当前可见分类顺序展示。
- 图标预览映射仅在开发环境启用，生产环境仍以后台图标配置为准。
- 保留多级分类路径、后台图标同步和全部重置逻辑。

## 验证记录

- H5 `npm run build`：通过。
- Playwright 登录后 320px、390px、480px 手机视口验证：通过。
- 三种宽度均保持每行 4 个分类入口，无页面横向溢出。
- 分类层级统计与标题同排，图标和滚动文字正常显示。
- 开发预览图片均能加载，子分类切换和全部重置验证通过。

## 影响范围

- 修改 H5 首页 `apps/h5/src/views/HomeView.vue`。
- 新增 H5 开发环境分类图标预览资源。
- 不修改后台分类数据、生产图标配置或其他客户端。
- 工作区中其他既有改动未纳入本版本提交。

# 喜易云 v1.52 更新说明

发布日期：2026-08-02

## 版本定位

`v1.52` 完成阿奇索失败回调的幂等收口，避免对方已经进入失败状态后仍重复通知。

## 主要更新

- 保留 `v1.51` 对阿奇索合法失败码 `9999` 的修复。
- 当本次目标状态为失败，且阿奇索明确返回当前已经是“请求失败”时，按幂等成功处理。
- 成功状态与阿奇索现有失败状态不一致时仍会报错，不会误判送达。
- 时间戳、签名、网络和其他业务错误继续进入原有重试流程。
- 自动恢复因非法失败码或“当前已经请求失败”而滞留的历史回调任务。
- 历史任务恢复只重发状态，不重新创建订单、扣款或采购。

## 验证范围

- 后端完整回归测试 420 项通过。
- 阿奇索失败码、签名、非 200 幂等确认和错误不误吞测试通过。
- 真实 MySQL 中三类历史回调任务恢复测试通过。
